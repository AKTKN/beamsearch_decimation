# SEARCH-BP-2.0 configuration legacy

SEARCH-BP-2.0 used `search_bp_config/3`, mandatory OSD-0 fallback, and
`search_bp_results/1`. It is retained as a historical identity only. Active runs
use SEARCH-BP-2.1, `search_bp_config/4`, and `search_bp_results/2`; old configs
are not silently accepted or relabeled.
